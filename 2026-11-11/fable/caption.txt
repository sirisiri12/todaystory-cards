AI가 8일 만에 OS를 만들고, 30시간 만에 수학 증명을 검증했다?! 클로드 '페이블 5.2' 공개 🤖

앤트로픽이 9일(미국 시간) 새 AI 모델 '클로드 페이블 5.2'와 '클로드 미토스 5.2'를 공개했어요. 두 모델은 같은 기반 모델이고, 페이블은 일반 사용자용, 미토스는 검증된 사이버보안·생명과학 기관용이에요.

📌 핵심만 정리
✔️ AI 평가 기관 Artificial Analysis 지능 지수 65점으로 1위 (제미나이 4 카본 60점)
✔️ 빈 폴더에서 시작해 서브 에이전트 1,000여 개가 8일간 작업 → 노트북에서 부팅되는 OS 시제품 제작
✔️ 에이전트 1,000개가 '페르마의 마지막 정리' 증명을 30시간 만에 컴퓨터 검증 언어로 형식화 (첫 시도는 11일)
✔️ 회로기판까지 직접 설계한 전자기기 3종이 수정 없이 작동
✔️ 5.1보다 최대 30% 빠르고, API 가격은 100만 토큰당 입력 8달러·출력 40달러

클로드 앱과 API 등에서 바로 쓸 수 있어요. 다만 위 성과는 대부분 앤트로픽 자체 발표·사전 테스트 기준이고, 사이버보안·생물학 고위험 요청은 차단돼요. 앤트로픽은 일상 작업엔 '오푸스 5.5'부터 써보라고 권장했어요.
